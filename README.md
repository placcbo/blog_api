# Blog API

A RESTful Blog API built with Go.

## Features

- Create a blog post
- Get all blog posts
- Get a single blog post
- Update a blog post
- Delete a blog post
- JSON request and response handling
- Request logging middleware

## Technologies

- Go
- net/http
- Chi router
- JSON
- In-memory storage
